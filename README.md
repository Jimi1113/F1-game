# Seoul GP 🏎️

브라우저에서 바로 즐기는 1인칭 F1 레이싱 게임이에요.
10번 그리드 맨 뒤에서 출발해서 봇 9대를 추월하고 3랩 레이스에서 1위를 노려보세요.

## 다운로드

1. 이 저장소의 **[seoul-gp.html](seoul-gp.html)** 파일을 눌러요.
2. 오른쪽 위의 **다운로드 버튼**(↓, "Download raw file")을 눌러 저장해요.
3. 받은 파일을 더블클릭하면 브라우저에서 게임이 열려요.

- 설치할 것이 없어요. 파일 하나로 끝이에요.
- 인터넷이 없어도 플레이할 수 있어요(인터넷이 있으면 글꼴만 조금 더 예쁘게 나와요).
- 크롬, 엣지, 사파리, 파이어폭스 최신 버전을 쓰는 윈도우, 맥, 리눅스 컴퓨터에서 잘 돌아가요.
- 휴대폰, 태블릿은 화면 버튼으로 조작할 수 있지만, 기기에 따라 내려받은 파일이 열리지 않을 수 있어요.

## 서킷

| 서킷 | 길이 | 특징 |
|---|---|---|
| 서울 | 5.9km · 코너 19개 | 한강변 메인 스트레이트, 광화문 앞 시가지 구간 |
| 세팡 | 5.54km | 열대의 늦은 오후, 실제 말레이시아 레이아웃 |
| 벨기에 | 7.0km · 고저차 102m | 오 루즈와 라디옹 오르막이 있는 아르덴 숲속 서킷 |

## 조작키

| 키 | 기능 |
|---|---|
| ↑ 또는 W | 가속 |
| S | 브레이크 |
| ↓ | 후진 |
| ← → | 조향 |
| Shift | DRS 열기 (DRS 구간에서만) |
| X | 부스트 켜기/끄기 |
| C | 시점 바꾸기 (콕핏 / 3인칭) |
| V | 사이드미러 켜기/끄기 |
| F | 공기 흐름 보기 |
| R | 재시작 |
| M | 소리 켜기/끄기 |
| Enter | 레이스 출발 |

## 플레이 팁

- **아웃-인-아웃**: 코너 바깥쪽에서 일찍 꺾어 들어가 안쪽 꼭짓점을 찍고 다시 바깥으로 나가면 가장 빨라요.
- **속도와 원심력**: 빠를수록 크게 돌아요. 고속 코너에서는 핸들을 더 많이 꺾어야 하고, 부족하면 바깥으로 밀려나요.
- **배터리와 부스트**: 배터리는 0%에서 시작하고, 브레이크를 밟아 속도를 줄인 만큼 충전돼요. X로 부스트를 켜면 직선에서 더 빨라져요.
- **DRS**: 초록 선이 있는 직선에서 Shift를 누르면 최고속이 올라가요.
- **슬립스트림**: 앞차 바로 뒤에서는 직선에서 공기저항이 줄지만, 코너에서는 다운포스가 줄어 미끄러지기 쉬워요.
- 화면이 끊기면 시작 화면의 그래픽을 **가볍게**로 바꿔 보세요.
